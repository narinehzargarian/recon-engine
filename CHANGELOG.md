# Changelog

## 0.1.0

First release.

- Matching by shared reference, one-to-one within an amount tolerance and date window, and groups less fees.
- Optimal assignment within clusters of competing transactions.
- Readers for OFX and QFX, versions 1 and 2, and for CSV with any column layout.
- Command-line tool with JSON and CSV reports, and exit codes for scheduled jobs.
- Self-hosted REST API backed by PostgreSQL.
